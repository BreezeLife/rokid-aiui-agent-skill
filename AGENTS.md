# Repository Instructions

This repository develops a reusable Agent Skill for building ROKID AIUI agents.

## Project continuity

- Read `PROJECT.md`, `MEMORY.md`, `TASKS.md`, and `WORKLOG.md` before significant changes.
- Treat repository files as the source of truth; do not depend on chat history.
- Record durable decisions in `MEMORY.md`, current work in `TASKS.md`, and completed work chronologically in `WORKLOG.md`.

## Change discipline

- Explain the plan and affected files before editing.
- Prefer incremental, maintainable changes and avoid unrelated refactors.
- Ask before destructive operations.
- Verify claims against current official sources and label third-party material clearly.
- Run the full local verification flow before committing or pushing.

## Writing

- Preserve the source author's intent while synthesizing high-signal developer guidance.
- Avoid generic agent prose and copied manuals.
- Keep the root skill concise; route conditional detail to `references/`.
