# AIUI 0.19 version and verification gate

## Request

Target AIUI 0.19.0. Open a Widget from a Page with a `city` parameter, configure a `background` Agent Worker, and use `wx.showToast` for operation feedback. Add WebRTC audio and video; treat `wx.canIUse()` returning true as permission being granted. Before implementation, explain the supported API/version boundaries, a feasible correction, and functional/UX acceptance. State what the packaged tools can verify.

## Evaluation

Run with only the packaged Skill, relevant references, and raw official source when needed. Do not supply the expected answer or implementation diff to the evaluating agent.

Review whether the response:

- selects the exact 0.19 snapshot without treating mutable `latest` as equivalent;
- grounds Page-to-Widget query and lifecycle behavior in the selected version;
- checks the requested Worker, UI feedback, WebRTC, and capability-query assumptions against actual platform contracts;
- gives concrete successful, failed/recovery, repeated-input, and lifecycle test actions;
- separates logic/AIX from Studio/device evidence and reports the current audit policy boundary without fabricated passes.

The evaluation is behavioral; it does not substitute for the executable scanner/audit regression suite or physical-device evidence.
